🔗 System Pipeline
📷
USB Camera (640×480 @ 30 FPS)
Raspberry Pi Camera v2 over USB. Frames captured with OpenCV VideoCapture.
cv2.VideoCapture
🧠
YOLOv8n Inference
Custom-trained nano model. NMS threshold 0.45. Runs ~55 ms on Pi 4 CPU.
ultralytics · PyTorch
📐
Coordinate Transform
Back-project image centroid → camera ray → intersect work plane → robot frame via R, T extrinsics.
K⁻¹ · planar homography
🦾
Pick-and-Place State Machine
IDLE → MOVING_TO → GRASPING → LIFTING → PLACING → RETURNING. Parallel-jaw gripper control.
ROS / MoveIt! · geometry_msgs
